## M16 的必做内容

M16 决定后面所有模块的前端接入方式，必须先做完再开其它模块的前端部分。

**后端**

- 新增 `chat_session` 表：`id`、`user_id`、`session_id`、`scene`、`title`、`last_message_at`、`status` 与六个公共字段
- 新增接口：新建会话（指定 `scene`）、会话列表、重命名、删除、清空
- **会话 ID 改由后端生成并返回**，前端不再自造 UUID；`assistant_message` 等已有表继续按 `session_id` 关联，结构不变
- 自动标题：取首条用户消息的前若干字

**前端**

- `DefaultLayout`：左侧栏（会话列表 + 资料库 + 设置入口）+ 右侧主内容区
- 会话 store：会话列表、当前会话、新建与切换
- 路由改为分层结构：壳作为父路由，会话与资料库页面作为子路由
- **默认进入新建会话**，不自动打开历史会话
- 把 M2 的通用助手页改造为会话类型之一（`scene`：`ASSISTANT`）
- 把 M4 的简历列表与编辑页挪到「资料库」分组

## 并行开发纪律

多个窗口同时开发时，以下文件是所有模块都会碰的共享文件：

`sql/career_assistant.sql`、`common/.../result/ErrorConstant.java`、`docs/技术约定.md`、`frontend/src/router/index.ts`、`frontend/src/views/HomeView.vue`、根 `pom.xml` 与各模块 `pom.xml`。

规则：

1. 只追加、不重排、不修改别人的行；每个模块在共享文件里用自己的分隔注释标明归属。
2. 错误码按号段分配，禁止跨段占用：1001–1049 账号与鉴权，1050–1099 通用助手与 Agent 通道，1100–1199 求职档案，1200–1299 简历，1300–1399 知识点与题库，1400–1499 诊断与匹配，1500–1599 面试，1600–1699 评价与掌握度，1700–1799 训练计划，1800–1899 记忆，1900–1999 向量检索，2000–2099 治理。
3. 每个窗口从 `dev` 新开分支（`dev-feature/<年月日>-<功能名>`），合并前先同步最新 `dev`。
4. M16 合入前，任何模块都不要改 `router/index.ts` 和 `HomeView.vue`，避免与壳的改造冲突。
